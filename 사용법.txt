AI 업스케일러 1.0.0
====================

작거나 흐릿한 이미지를 AI(Real-ESRGAN)로 2~4배 선명하게 키워 주는 Windows 프로그램이에요.
Upscayl과 같은 엔진(upscayl-bin)을 써서 그래픽카드(GPU)로 처리하고, 모든 작업은 이 PC 안에서 이뤄져요.
인터넷은 '모델 더 받기'를 누를 때만 사용해요.


■ 설치와 실행
  설치판: AI-Upscaler-Setup-버전.exe 를 실행하면 설치돼요 (관리자 권한 필요 없음).
          시작 메뉴나 바탕 화면의 'AI 업스케일러'로 실행하세요.
          설치 위치: %LOCALAPPDATA%\Programs\AI-Upscaler
  압축판: AI-Upscaler-버전-portable.zip 을 푼 뒤 AI-Upscaler.exe 를 더블클릭하세요.
          (압축 파일 안에서 바로 실행하지 말고, 먼저 압축을 모두 풀어 주세요.
           engine 폴더는 AI-Upscaler.exe 와 같은 폴더에 그대로 두세요.)

  처음 실행할 때 "Windows의 PC 보호" 파란 창이 뜨면
  → '추가 정보'를 누르고 → '실행'을 누르세요.
  (인터넷에서 받은 서명 없는 프로그램이라 나오는 안내예요.)

  삭제: 설정 → 앱 → 설치된 앱 → 'AI 업스케일러' → 제거
        (업스케일한 결과 이미지는 지워지지 않아요.)


■ 필요한 것
  - Windows 10 또는 11 (64비트)
  - Vulkan을 지원하는 그래픽카드와 최신 드라이버
    (최근 10년 안에 나온 NVIDIA·AMD 그래픽카드, 인텔 내장 그래픽 대부분이 해당돼요)
  - WebView2 런타임: Windows 10/11에 보통 이미 들어 있어요.
    없으면 프로그램이 자동으로 Edge(또는 크롬) 창으로 열려요.


■ 쓰는 방법
  1. 이미지 넣기: '이미지 고르기' / '폴더 고르기'를 누르거나,
     이미지를 창에 끌어다 놓거나, 복사한 이미지를 Ctrl+V로 붙여넣으세요.
  2. AI 모델 고르기
     - 일반 사진: 사진·실사에 가장 무난해요 (기본값, Upscayl Standard와 같은 모델)
     - 빠른 모드: 조금 덜 선명하지만 훨씬 빨라요
     - 디지털 아트·일러스트: 애니메이션, 웹툰, 그림
     - 애니메이션 (가벼움): 애니 영상 캡처용, 2·3·4배를 직접 지원
     - '모델 더 받기'에서 고화질 디테일, 아주 선명하게(UltraSharp), Remacri, UltraMix를
       추가로 받을 수 있어요 (각 약 34MB).
  3. 배율 고르기: 2배 / 3배 / 4배
  4. 저장 형식과 위치 고르기
     - PNG: 화질 손실 없음 (파일이 큼)  /  JPG: 파일이 작음  /  WebP: 작고 품질 조절 가능
     - 위치: '원본과 같은 폴더' 또는 '지정한 폴더'
       (끌어다 놓거나 붙여넣은 이미지는 원래 위치를 알 수 없어서 지정한 폴더에 저장돼요.
        기본값은 '사진\AI-Upscaler' 폴더예요.)
  5. '업스케일 시작'을 누르세요. 처리 중에는 '멈추기'로 멈출 수 있어요.
  6. 결과 확인: 미리보기 가운데의 주황색 선을 좌우로 끌면 원본과 결과를 비교할 수 있어요.
     - 마우스 휠: 확대·축소, 끌기: 이동, 두 번 클릭: 화면 맞춤 ↔ 실제 크기
     - '원본 픽셀 보기'를 켜면 원본을 부드럽게 늘리지 않고 픽셀 그대로 보여 줘요.
     - '결과 열기', '폴더에서 보기'로 저장된 파일을 바로 열 수 있어요.

  결과 파일 이름: 원래이름_upscaled_4x_standard.png 처럼 배율과 모델 이름이 붙어요.
  같은 이름의 파일이 있으면 덮어쓰지 않고 " (2)"를 붙여 따로 저장해요.

  키보드: Ctrl+O 이미지 고르기, ←/→ 이전·다음 이미지, Delete 목록에서 빼기,
          + / - 확대·축소, 0 화면 맞춤, 1 실제 크기


■ 고급 설정 (왼쪽 아래 톱니바퀴)
  - 그래픽카드: 노트북처럼 GPU가 둘이면 '자동'이 성능 좋은 쪽을 골라요.
  - 타일 크기: "그래픽 메모리가 부족하다"는 오류가 나면 128이나 64로 줄이세요.
  - 고품질 모드(TTA): 조금 더 깨끗해지지만 처리 시간이 약 8배 걸려요.
  - 창 모드: 앱 창이 제대로 안 뜨면 '웹 브라우저로 열기'로 바꾸세요.


■ 문제가 생기면
  - "Vulkan ... 찾지 못했어요" / "엔진에 문제가 있어요"
    → 그래픽카드 드라이버(NVIDIA·AMD·Intel 홈페이지)를 최신으로 설치하고 '엔진 다시 확인'.
  - "그래픽 메모리가 부족해요" → 고급 설정에서 타일 크기를 줄이세요.
  - 앱 창이 안 뜨거나 하얗게 나와요
    → 고급 설정의 창 모드를 '웹 브라우저로 열기'로 바꾸거나,
      AI-Upscaler.exe 바로 가기의 대상 끝에 --browser 를 붙여 실행하세요.
  - 휴대폰 사진도 방향(회전)이 맞게 결과가 나와요.
  - 기록 파일: %LOCALAPPDATA%\AI-Upscaler\logs\app.log
    (고급 설정 → '기록 폴더'로 바로 열 수 있어요)
  - 설정 파일: %APPDATA%\AI-Upscaler\settings.json (지우면 처음 상태로 돌아가요)


■ 폴더 구성 (설치 폴더)
  AI-Upscaler.exe   프로그램 (화면과 작업 관리)
  uninstall.exe     삭제 프로그램 (설치판)
  engine\           업스케일 엔진 (upscayl-bin.exe, vcomp140.dll) 과 AI 모델(models)
  licenses\         함께 들어 있는 구성 요소들의 라이선스


■ 직접 빌드하려면 (소스 코드 폴더)
  1. Go(1.24 이상)를 설치하세요: https://go.dev/dl/
  2. 소스 폴더의 build.bat 을 더블클릭하세요.
     처음 한 번은 엔진과 기본 모델(약 55MB)을 GitHub 에서 받아요.
  3. dist 폴더에 설치 파일(AI-Upscaler-Setup-버전.exe)과 압축판이 만들어져요.
  자세한 내용은 README.md 를 보세요.
